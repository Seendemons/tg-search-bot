# Telegram Search Bot

Бот ищет статьи в Wikipedia, репозитории на GitHub и вопросы на Stack Overflow.

## Запуск

Для проекта используется Python 3.13. Установите менеджер пакетов uv, если его ещё нет. [Инструкция по установке uv](https://docs.astral.sh/uv/getting-started/installation/)

1. Создайте бота через `/newbot` у `@BotFather` и скопируйте выданный токен. [Инструкция Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token)
2. В корне проекта, рядом с `pyproject.toml`, создайте файл `.env` и подставьте токен вместо `ваш_токен`.

   ```dotenv
   BOT_TOKEN=ваш_токен
   ```

   Файл `.env` исключён из Git.
3. Откройте терминал в корне проекта и запустите бота. При первом запуске uv установит зависимости.

   ```bash
   uv run first-bot
   ```

## Проверка

Откройте личный чат с ботом и отправьте `/start`. Затем отправьте `/search` и после вопроса «Что будем искать?» напишите `Python programming`. Бот пришлёт результаты поиска по трём источникам.

Чтобы остановить бота, нажмите `Ctrl+C` в терминале.
